# 主数据建模 - 主页面 需求详细说明书

> 版本：1.0 | 面向：前端开发  
> 本文档细化"主数据建模主页面"的完整业务逻辑、交互细节和前端状态管理，用于支撑AI编码。

---

## 1. 页面总体结构

### 1.1 布局说明

主页面采用 **左右分栏布局**，整体结构如下：

**左侧区域**为"主题域分类树"面板，默认宽度约 250～300px（可通过拖拽调整），用于展示主题域的树形分类结构。左侧面板在用户从未创建过任何主题分类时隐藏，此时右侧内容区占满全宽。

**右侧区域**为"模型展示区"，从上到下又分为三个工具栏层和一层内容区：

- **操作按钮区**：位于最上方，包含新建模型、复制模型、导入模型、复用资产、删除、移动、导出等操作按钮，以及右侧的"主题域管理"入口和"显示级联数据"复选框。
- **搜索/筛选/排序工具栏**：位于操作按钮区下方，包含视图切换按钮（卡片/列表）、排序标签（按名称、按创建时间）、模型类型下拉筛选、关键词搜索输入框（支持按 Enter 键和点击搜索图标触发）、状态下拉筛选。
- **内容区**：位于工具栏下方，占据剩余全部空间，根据用户选择的视图模式（卡片视图或列表视图）渲染模型卡片或数据表格。页面无全局底栏。

整体布局通过 `TpLeftTreeLayout` 组件实现，接收 `#left` 和 `#right` 两个命名插槽。

### 1.2 两种页面模式

| 条件 | 页面形态 |
|------|---------|
| 用户从未进行过主题域管理（即不存在任何主题分类） | 无左侧树，右侧全宽平铺展示所有模型 |
| 用户已创建主题分类 | 左侧显示主题域分类树 + 右侧展示所选节点下的模型 |

**前端状态要点**：进入页面时，先请求主题树数据。若返回为空数组，则隐藏左侧树区域，右侧全宽渲染；否则显示左右分栏。

### 1.3 权限控制

- **管理范围**：当前用户仅能看到自己具有"模型管理权限"的模型。
- 左侧分类树：**不做权限控制**，显示全部分类节点。
- 右侧模型列表/卡片：仅显示当前用户有管理权限的模型。

## 2. 左侧主题域分类树

### 2.1 树组件基本行为

| 属性 | 说明 |
|------|------|
| 默认选中 | 进入菜单时，默认选中根节点"主题域" |
| 默认展开 | 仅展开所有一级主题域，二级及以下默认收起 |
| 展开/收起 | 点击节点前的展开箭头图标，切换子节点的展开/收起 |
| 节点选中 | 点击节点文本区域，高亮选中，右侧刷新为对应模型数据 |
| 搜索 | 支持关键字模糊搜索，搜索范围为主题名称 |

### 2.2 "显示级联数据"勾选框

- **位置**：树组件顶部，紧邻搜索框
- **默认状态**：勾选（true）
- **勾选时**：选中某节点，右侧显示该节点及其所有子节点下的全部模型
- **未勾选时**：选中某节点，右侧仅显示该节点直属的模型，不包含子节点数据

### 2.3 节点选中后的右侧行为

| 选中的节点类型 | 右侧按钮状态 |
|---------------|-------------|
| 根节点"主题域" | "新建模型"、"复制模型"、"导入模型"、"复用资产"按钮 **置灰禁用**；其他按钮正常 |
| 非末级主题节点 | 同上（"新建模型"、"复制模型"、"导入模型"、"复用资产"按钮 **置灰禁用**） |
| 末级主题节点 | 所有按钮正常可用 |

**禁用原因提示**（鼠标hover置灰按钮时显示）："请先选择末级分类后再创建模型"

## 3. 主题域管理

### 3.1 入口

点击页面工具栏的 **"主题域管理"** 按钮，右侧弹出**模态弹窗**（Modal Dialog），展示主题域管理页面。

### 3.2 弹窗内页面结构

```
┌──────────────────────────────────────┐
│  主题域管理                     [×]   │
├──────────────────────────────────────┤
│  工具栏：[新增] [导入] [导出] [删除]   │
│  ☐ 显示级联数据（默认不勾选）         │
├──────────────────────────────────────┤
│  主题域列表（树形表格 / 行编辑模式）    │
│  列：排序号 | 主题名称 | 备注 | 操作   │
│  支持分页                              │
└──────────────────────────────────────┘
```

**弹窗内"显示级联数据"**：
- 默认不勾选
- 勾选时：选中某节点，列表显示该节点及子节点下的模型数量统计
- 未勾选时：仅显示直属模型数量

### 3.3 新增主题

#### 3.3.1 操作流程

1. 用户在列表中选择某个分类节点
2. 点击"新增"按钮
3. 系统在该选中节点的下一级插入新行（位于同级最上方），自动获得焦点

#### 3.3.2 前置校验

- 若选中主题下**已存在主数据模型**（含级联子主题下的模型），阻止新增，Toast提示：`"该主题下维护了模型，不能增加子主题。"`

#### 3.3.3 字段定义

| 字段 | 类型 | 必填 | 最大长度 | 校验规则 |
|------|------|------|---------|---------|
| 排序号 | 数字输入框 | 是 | - | 默认值 = 当前同级最大排序号 + 1；正整数 |
| 主题名称 | 文本输入框 | 是 | 50字符 | ① 非空；② 同一父节点下不可重复（区分大小写）；③ 仅允许：汉字、英文字母、数字、"-"、"_"；④ "-"和"_"不能位于首位；⑤ 大小写敏感 |
| 备注 | 文本输入框 | 否 | 200字符 | 超长时提示：`"请最多输入200个字。"` |

#### 3.3.4 保存校验逻辑（按顺序执行）

```
1. 非空校验 → 排序号和主题名称为空 → 输入框标红 + 提示"该输入项为必填项"
2. 格式校验 → 主题名称含非法字符 → 输入框标红 + 提示"请最多输入50个字符，字符支持汉字、英文字母、数字、'-'、'_'，且符号不能位于首位。"
3. 长度校验 → 字段超长 → 输入框标红 + 对应长度提示
4. 唯一性校验 → 同父节点下名称重复 → 提示"主题名称在该层级下已存在"
5. 全部通过 → 保存成功 → 刷新列表 → 关闭编辑状态
```

### 3.4 编辑主题

- 点击行操作列的"编辑"按钮，该行进入**行内编辑状态**
- 编辑字段和校验逻辑与"新增"完全一致
- 保存后刷新列表

### 3.5 删除主题（支持批量）

#### 3.5.1 操作流程

```
用户勾选一个或多个主题行前的复选框
  ↓
点击"删除"按钮
  ↓
校验1：是否选中任何记录？
  → 否 → Toast："请至少选择一条记录进行操作！"
  ↓ 是
校验2：所选主题或其级联子主题下是否存在主数据模型？
  → 是 → Toast："所选主题下存在模型，不允许删除！"
  ↓ 否
弹出确认对话框
  → 提示文案："确定删除所选主题及其所有子主题？"
  → [确定] → 批量删除所选分类及所有子主题 → 刷新列表
  → [取消] → 关闭对话框，不执行
```

### 3.6 导入主题

#### 3.6.1 操作流程

1. 点击"导入"按钮，弹出导入弹窗
2. 弹窗内提供"下载模板"链接
3. 用户上传 Excel 文件（支持 .xlsx / .xls / .et）
4. 点击"确定"开始解析

#### 3.6.2 导入模板格式

| 列名 | 必填 | 表头批注提示 |
|------|------|-------------|
| 上级主题 | 是 | `"必填，输入完整的分类层级，不包含根节点，各级主题间用'|'分割，如：生产制造\|制造执行管理。"` |
| 主题名称 | 是 | `"必填，当前层级下要求唯一，请最多输入50个字符，字符支持汉字、英文字母、数字、'-'、'_'，且符号不能位于首位。"` |
| 说明 | 否 | `"非必填，最多输入200个字符！"` |
| 排序号 | 是 | `"必填，正整数"` |

#### 3.6.3 解析与校验

解析过程中显示实时进度条。校验逻辑与"新增主题"保持一致，包括：上级主题存在性、主题名称规范性、必填项、长度、同层级唯一性。

#### 3.6.4 导入结果反馈

```
解析完成后显示：
"共导入【X】条分类数据，成功【Y】条，失败【Z】条。"

若 Z > 0：
  → 显示"下载失败记录"按钮
  → 失败记录Excel中：
     - 不合规单元格红色底色标识
     - 鼠标悬浮时Tooltip显示失败原因
```

#### 3.6.5 失败原因枚举

| 失败原因 | 触发条件 |
|---------|---------|
| `上级主题不存在` | 填写的上级主题路径在系统中找不到 |
| `该主题下已维护模型` | 上级主题下已有主数据模型 |
| `分类名称不符合填写要求` | 主题名称含非法字符或格式不合规 |
| `分类名称长度超过50个字符` | 超出长度限制 |
| `分类名称必填` | 主题名称为空 |
| `主题名称在该主题下重复` | 同一级分类下名称不唯一 |

### 3.7 导出主题

- 导出选中节点下的全部主题数据
- 导出格式与导入模板一致
- 按排序号排序导出
- 支持基于过滤条件的数据导出

## 4. 右侧模型展示区

### 4.1 视图切换

| 属性 | 卡片视图（默认） | 列表视图 |
|------|----------------|---------|
| 切换图标 | 页面右上方图标组 | 同左 |
| Tooltip | 鼠标移入显示"卡片布局" | 鼠标移入显示"列表布局" |
| 默认 | ✓ | - |

**交互细节**：
- 图标组为两个紧邻的图标按钮，当前选中的视图图标高亮
- 鼠标移出图标区域时隐藏 Tooltip
- 切换视图时保持当前搜索、筛选、排序条件不变

### 4.2 空状态

当当前选中节点下无任何模型时，显示空状态占位：

```
        ┌─────────────┐
        │   空状态插图   │
        │  "暂无数据，   │
        │    请创建"     │
        └─────────────┘
```

### 4.3 排序

| 排序维度 | 默认 | 切换 |
|---------|------|------|
| 按名称 | A→Z 升序（默认） | 点击切换为 Z→A 降序 |
| 按创建时间 | 最新→最早 降序 | 点击切换为 最早→最新 升序 |

- 排序控件为下拉选择器，选项为"按名称"和"按创建时间"
- 每个选项旁有升降序切换图标箭头

### 4.4 条件搜索

#### 4.4.1 搜索条件

| 条件 | 控件类型 | 触发方式 |
|------|---------|---------|
| 状态 | 下拉选择框 | 选中后自动刷新列表（无需点击搜索） |
| 模型类型 | 下拉选择框 | 选中后自动刷新列表（无需点击搜索） |
| 模型名称/编码 | 文本输入框 | 输入关键词后，点击搜索图标或按 Enter 键触发模糊搜索（不区分大小写） |

#### 4.4.2 搜索框交互

- 输入框右侧有搜索图标按钮（点击触发搜索）
- 输入框内有清除按钮（×），点击一键清空输入内容并刷新列表
- 按 Enter 键触发搜索

### 4.5 页面刷新触发条件

以下操作完成后，自动刷新右侧模型列表/卡片数据：
- 新增模型成功
- 删除模型成功
- 移动模型成功
- 复制模型成功
- 复用资产成功

## 5. 卡片视图详细设计

### 5.1 卡片信息展示

每张卡片显示以下信息：

| 字段 | 说明 | 样式 |
|------|------|------|
| 模型名称 | 主标题 | 粗体，超长截断+Tooltip |
| 模型编码 | 副标题 | 常规字体 |
| 表名称 | 数据库表名 | 常规字体 |

| "授权"按钮 | 点击 | 右侧滑出授权抽屉页面 |

### 5.3 卡片布局响应式

- 基准分辨率 1920×1080：每行 4~5 张卡片
- 卡片列表支持分页或滚动加载

## 7. 新建模型

### 7.1 前置条件

- 左侧必须选中**末级主题节点**，否则"新建模型"按钮置灰
- 按钮置灰时 hover 提示："请先选择末级分类后再创建模型"

### 7.2 操作流程

1. 选中末级主题 → 点击"新建模型"按钮
2. 弹出新建模型表单（弹窗或路由页面，以UI设计为准）
3. 填写模型基本信息
4. 点击"保存" → 校验通过 → 进入"模型管理"页签

### 7.3 模型基本信息字段

| 字段 | 控件类型 | 必填 | 最大长度 | 校验规则 | 默认值 |
|------|---------|------|---------|---------|--------|
| 目标数据源 | 下拉选择 | 是 | - | 选项为"统一数据源"中注册的主数据库；若仅有1个主数据库则自动回填 | 无 |
| 模型名称 | 文本输入 | 是 | 300字符 | ① 非空；② 全局唯一（区分大小写）；③ 仅允许：中文、字母、数字、"_"；④ 大小写敏感 | 空 |
| 模型编码 | 文本输入 | 是 | 300字符 | ① 非空；② 全局唯一（区分大小写）；③ 仅允许：中文、字母、数字、"_"；④ 大小写敏感 | 空 |
| 表名称 | 文本输入 | 是 | 300字符 | ① 非空；② 同一数据库下唯一（区分大小写）；③ 仅允许：中文、字母、数字、"_"；④ **必须以字母或中文开头**；⑤ 大小写敏感 | 空 |
| 模型类型 | 下拉选择 | 是 | - | 选项："普通模型"、"复合模型"、"分类模型" | 无 |
| 模型密级 | 下拉选择 | **条件必填** | - | 仅当密级管理开启时显示；选项来自"数据密级"字典的启用值；不允许选择大于当前人员密级的值 | 无 |
| 备注 | 多行文本 | 否 | 1200字符 | 超长截断提示 | 空 |
| 关联标准文件 | 文件上传+关联已有 | 否 | - | 详见7.4 | 空 |

### 7.4 关联标准文件

#### 7.4.1 两种关联方式

**方式一：上传新文件**
1. 点击"上传"按钮，弹出上传弹窗
2. 弹窗交互完全复用"治理平台-数据规划-数据管理制度-上传文档"
3. 上传的文档统一在"治理平台-数据规划-数据管理制度"菜单下管理
4. 上传完成后在下方文件列表中显示

**方式二：关联已有文件**
1. 点击"关联已有文件"按钮
2. 弹窗显示"治理平台-数据规划-数据管理制度"下的文件
3. 页面以树列表形式展现
4. 支持通过文件名称模糊查询
5. 右侧列表支持分页
6. 选择文件后确认关联

#### 7.4.2 已关联文件管理

- 文件列表平铺展示文件名称，按上传/关联先后顺序排列
- 超出页面宽度后换行显示
- 每个文件提供两个操作图标：
  - 🔍 **预览**：打开新页面预览文件。支持预览的格式：xlsx、xls、docx、doc、jpg、png、txt、pptx、pdf。不支持的格式提示：`"该文件类型'***'不支持预览。"` 文件异常时提示：`"找不到该文件。"`
  - 🗑️ **删除**：解除该文件与模型的关联
- 内容超出可视区域时右侧自动出现滚动条

### 7.5 复合模型 - 子模型管理

#### 7.5.1 触发条件

当"模型类型"选择 **"复合模型"** 时，表单下方自动展开"子模型信息"区域。

#### 7.5.2 子模型列表

| 字段 | 类型 | 最大长度 | 填写规则 | 约束规则 |
|------|------|---------|---------|---------|
| 序号 | 字符 | 10 | 初始值为1，新增时自动+1 | 系统自动生成 |
| 模型名称 | 字符 | 300 | 自动生成：主模型名称+"_01"/"_02"…，支持修改 | 必填，全局唯一，仅允许中文/字母/数字/"_"，大小写敏感 |
| 模型编码 | 字符 | 300 | 自动生成：主模型编码+"_01"/"_02"…，支持修改 | 必填，全局唯一，仅允许中文/字母/数字/"_"，大小写敏感 |
| 表名称 | 字符 | 300 | 自动生成：主表名称+"_01"/"_02"…，支持修改 | 必填，同一数据库下唯一，仅允许中文/字母/数字/"_"且须以字母或中文开头，大小写敏感 |
| 备注 | 字符 | 1200 | 无 | 非必填 |

#### 7.5.3 子模型操作

| 操作 | 条件 | 说明 |
|------|------|------|
| 新增子模型 | 编辑中 | 添加一行新的子模型，序号自动+1，名称/编码/表名自动生成 |
| 停用 | 最高版本状态为"启用" | 停用后模型名称前增加红色"(已停用)"标识；在数据维护/查看场景下不显示 |
| 启用 | 最高版本为"停用"状态 | 启用后版本与主模型一致，恢复正常显示 |
| 删除 | 仅版本为1且状态为"编辑中" | 从复合模型中移除该子模型 |

### 7.6 保存逻辑

```
点击"保存"
  ↓
前端表单校验：
  1. 目标数据源：必填
  2. 模型名称：非空 + 格式 + 长度 + 全局唯一性
  3. 模型编码：非空 + 格式 + 长度 + 全局唯一性
  4. 表名称：非空 + 格式（首字母/中文开头）+ 长度 + 同数据库下唯一性
  5. 模型类型：必选
  6. 模型密级（若开启）：必选
  ↓
校验不通过 → 对应输入框标红 + 气泡提示原因
  ↓
校验全部通过 → 调用保存接口
  ↓
保存成功：
  - 生成版本 V1、状态"编辑中"的模型记录
  - 关闭弹窗/返回主页面
  - 自动刷新模型卡片/列表数据
  - 进入"模型管理"页签
```

### 7.7 生效操作（从新建模型后）

- 仅对最高版本为"编辑中"的模型可执行
- 复合模型生效时，强校验主表是否配置了"匹配字段"，未配置则提示：`"主表必须配置匹配字段。"`
- 生效时物理层面校验表名称在目标数据源下是否唯一
- 生效后发布物理表（创建/更新数据库表结构）

### 11.1 操作流程


## 15. 状态机 - 模型生命周期

### 15.1 模型状态定义

```
           ┌─────────┐
   新建 ──→│  编辑中   │
           └────┬────┘
                │ 生效
                ↓
           ┌─────────┐
    ┌──────│   生效    │──────┐
    │      └────┬────┘      │
    │ 修订       │ 停用      │ 删除（仅编辑中版本）
    │           ↓           │
    │      ┌─────────┐     │
    │      │   停用    │     │
    │      └────┬────┘     │
    │           │ 启用      │
    │           ↓           │
    │      ┌─────────┐     │
    │      │   生效    │     │
    │      └─────────┘     │
    │                      │
    │ 修订产生新版本         │
    │ V(N) → V(N+1)编辑中   │
    │ V(N)生效 → 历史       │
    │                      │
    │      ┌─────────┐     │
    └─────→│  审核中   │    │
           └─────────┘     │
                │           │
                ↓           │
           ┌─────────┐     │
           │ 生效/驳回│     │
           └─────────┘     │
                           │
      ┌─────────┐         │
      │   历史   │←────────┘
      └─────────┘
```

### 15.2 不同状态下的操作按钮

| 最高版本状态 | 可用操作 |
|-------------|---------|
| 编辑中 | 生效、编辑、删除、数据规范、版本对比、版本选择 |
| 审核中 | 流程跟踪、数据规范、版本对比、版本选择 |
| 生效 | 修订、停用、数据规范、版本对比、版本选择 |
| 停用 | 启用、数据规范、版本对比、版本选择 |

## 17. 异常与边界场景

| 场景 | 处理方式 |
|------|---------|
| 网络异常 | 显示网络错误提示 + 重试按钮 |
| 接口超时 | 显示超时提示 + 重试按钮 |
| 主题树数据为空 | 隐藏左侧树，右侧全宽平铺 |
| 某分类下模型数量 > 10000 | 使用虚拟滚动或分页 |
| 并发删除同一模型 | 接口返回冲突错误，前端提示"该模型已被其他用户操作，请刷新后重试" |

| 用户无目标数据源权限 | "新建模型"按钮置灰，提示"无可用数据源，请联系管理员" |
