# 主数据建模模块 — 需求说明书

> 最后更新：2026-06-23
> 关联模块：model-design（apps/mdm-model/src/modules/model-design/）
> 需求文档：`docs/主数据建模模块需求说明书V1.1.docx`

---

## 1. 模块定位

主数据建模（model-design）是 mdm-model 应用的核心模块，提供主数据的**可视化建模能力**，支撑主数据的全生命周期管理与规范化应用。

## 2. 业务流程

### 2.1 初始化操作

```
主题域管理（可选）→ 主数据建模（新建/导入/复用资产）→ 属性配置 → 填报设计 → 编码规则 → 相似规则 → 质量规则 → 模型送审/生效
```

### 2.2 已有实施成果，环境迁移/复制

```
行业资产库（提取资产）→ 行业资产库（导出）→（新环境）行业资产库（导入）→ 主数据建模（复用资产）→ 模型批量送审/生效
```

## 3. 主要功能模块

### 3.1 行业资产库

提供标准化的主数据模型，实现资产的集中管理、沉淀与复用。

| 功能 | 说明 |
|------|------|
| 内置标准模型资产 | 预置供应商、人员、物料、产品等企业核心业务实体模型，开箱即用 |
| 资产卡片列表 | 分页加载，支持按名称升序/降序排序 |
| 查看 | 进入资产信息页面，支持模型管理、属性配置、填报设计、相似规则、编码规则、质量规则 6 个页签 |
| 导出 | 打包导出模型结构、属性配置、填报设计、相似规则、编码规则及质量规则，文件加密 |
| 导入 | 跨环境资产迁移，校验文件结构一致性，自动处理重名（追加 _01/_02 后缀） |
| 提取资产 | 从"主数据模型"提取为"资产"，支持批量选择和资产信息编辑 |
| 删除 | 勾选卡片后删除，需二次确认 |

### 3.2 主题域管理

对主数据模型进行分类管理。

| 功能 | 说明 |
|------|------|
| 新增 | 在分类下添加子分类，光标自动定位到新增行 |
| 编辑 | 行进入编辑状态，校验规则同新增 |
| 删除 | 批量删除，需校验是否有关联模型 |
| 导入 | 下载模板后解析导入，支持下载失败记录 |
| 导出 | 导出主题列表数据，与导入格式一致 |

### 3.3 主数据建模（主页）

支持列表和卡片两种形式展现主数据模型。

| 功能 | 说明 |
|------|------|
| 展示形式 | 卡片/列表两种形式，默认卡片，支持切换 |
| 新建模型 | 在末级主题下创建，支持普通模型、复合模型、分类模型 |
| 复制模型 | 复制已有模型及配置信息到当前分类 |
| 复用资产 | 从行业资产库选择资产快速建模，支持批量（≤20 实时，>20 异步） |
| 移动模型 | 将模型移动至其他末级分类 |
| 导入/导出 | 支持按条件导出，导入见专项功能 |
| 授权 | 对模型进行授权管理 |

**复合模型特殊说明**：
- 主模型 + 多个子模型结构
- 子模型支持单独停用/启用
- 子模型停用后在继配置页签显示"（已停用）"标识

### 3.4 模型管理

通过定义属性来构建标准化的主数据模型。

| 功能 | 说明 |
|------|------|
| 模型信息管理 | 展示/编辑模型基本信息，支持版本切换 |
| 版本管理 | V1→V2→V3...，保留历史版本，支持版本对比（全部属性/差异属性） |
| 生效 | 确定模型信息，创建物理表，校验表名唯一性 |
| 停用/启用 | 停用后相关应用不可见，启用后恢复 |
| 属性字段管理 | 新增/编辑/删除属性，支持从数据标准库批量关联 |
| 属性导入/导出 | 支持批量导入属性，导出当前版本启用属性 |

**属性字段说明**：

| 字段 | 说明 |
|------|------|
| 属性名称 | 业务名称，必填，唯一，≤200 字符 |
| 英文名称 | 字段名称，必填，唯一，≤200 字符 |
| 数据类型 | 根据主数据库类型选择 |
| 长度/精度 | 字符串最大 4000，数值最大 38 |
| 是否必填 | 默认是，启用后自动生成非空规则 |
| 是否唯一 | 唯一性约束 |
| 状态 | 启用/停用 |

### 3.5 属性配置

为模型字段提供精细化数据定义能力。

| 配置项 | 说明 |
|--------|------|
| 流程关键字段 | 作为流程待办名称，区分同一流程下的业务对象 |
| 匹配字段 | 数据新增/导入时的唯一标识，复合模型主表匹配字段同时用于主子表关联 |
| 文件字段 | 字符型/大文本型可配置，上传附件控件 |
| 关联对象 | 关联数据字典或数据模型，支持多选、显示字段、带出字段、赋值字段、过滤规则 |
| 计算表达式 | 可视化表达式配置，支持四类函数（字符/数值/转换/逻辑），支持 Groovy 脚本 |

**关联对象配置**：
- 关联模型/关联字典
- 关联字段（多选）、显示字段
- 是否多值
- 带出字段：选择引用值时带出其他字段
- 赋值字段：自动赋值给其他字段
- 过滤规则：级联过滤（如：选省后代市）

### 3.6 填报设计

灵活定义数据填报表单。

| 配置项 | 说明 |
|--------|------|
| 属性分组 | 将属性归类显示，分组间拖拽排序 |
| 属性样式 | 输入方式（单行/多行/下拉/弹窗/日期等）、提示信息、提示效果 |
| 显隐条件 | IF 表达式控制字段显隐 |
| 布局样式 | 表单布局（单/双/三/四列）、字段布局（左右/上下） |
| 表单预览 | 预览数据维护页面效果 |

### 3.7 数据样式

配置数据展现形式和排序。

| 配置项 | 说明 |
|--------|------|
| 展现形式 | 列表/树/树列表 |
| 树配置 | 子字段、父字段、显示字段、级联显示父模型 |
| 排序设置 | 按属性优先级和升序/降序排列 |

### 3.8 相似规则

支持基于属性相似度的数据查重。

| 功能 | 说明 |
|------|------|
| 四种算法 | 包含与被包含、等于、余弦定理、编辑距离 |
| 相似度阈值 | 0-100%，综合相似度≥阈值则定义为"相似" |
| 权重配置 | 多规则按权重分配，支持相对权重计算 |
| 实时检查 | 新增时实时检查，批量导入时可选全部/仅非相似导入 |

### 3.9 编码规则

确保编码唯一性与规范性。

| 功能 | 说明 |
|------|------|
| 码段管理 | 支持 9 种码段灵活组装 |
| 生成方式 | 自动生成/手动触发/生效时生成 |
| Groovy 脚本 | 可视化编辑器，支持自定义编码规则 |

### 3.10 质量规则

确保数据标准落地。

| 功能 | 说明 |
|------|------|
| 规则类型 | 非空规则、格式规则、自定义规则 |
| 规则配置 | 基于属性配置质量校验规则 |
| 入库校验 | 数据入库时自动校验 |

## 4. 全局交互规范

### 4.1 列表展示

| 规范 | 说明 |
|------|------|
| 空状态 | 插图+提示文案"暂无数据，请创建" |
| 内容截断 | 单行显示，超长显示省略号，hover 气泡显示完整内容 |
| 分页 | 默认 20 条/页，支持 20/50/100/200 切换，显示总数 |
| 快速跳转 | 支持输入页码跳转 |

### 4.2 树搜索

- 模糊匹配，不区分大小写
- 展开所有匹配节点及其父级，未匹配节点折叠
- 定位到第一条匹配结果

### 4.3 下拉选项

- 滚动加载：优先加载 30 个选项，滚动到底部自动加载
- 后端搜索：支持关键词过滤

### 4.4 导入导出

- 导入：根据数据量自动选择实时/异步模式
- 导出：支持按过滤条件导出

## 5. 实体模型

| 实体 | 说明 |
|------|------|
| Topic（主题域） | 树形结构，支持层级分类 |
| Model（主数据模型） | 核心建模单元，含版本与状态机 |
| Attribute（属性） | 模型下的字段定义 |
| CodingRule（编码规则） | 模型编码生成规则 |
| QualityRule（质量规则） | 数据质量校验规则 |
| SimilarityRule（相似度规则） | 查重/合并规则 |
| FormDesign（填报设计） | 动态表单定义 |

### 5.1 状态机

| 实体 | 状态 |
|------|------|
| Model | draft → published → archived |
| Attribute | enabled / disabled |
| FormDesign | draft / published |

## 6. 权限与角色

- **实施顾问**、**对应业务域数据管家**：具有主数据建模功能权限

## 7. 与其他模块的关系

| 关联模块 | 说明 |
|----------|------|
| 行业资产库 | 资产复用、提取、导入导出 |
| 数据标准 | 属性可关联数据元标准 |
| 数据源管理 | 主数据库类型，模型关联数据源 |
| 数据维护 | 建模成果在数据维护模块使用 |
| 流程管理 | 送审、生效流程 |
