# 国际化（i18n）规范

> 本文件定义前端国际化的 Key 命名空间、语言包结构、铁律。
> 本文件规则适用于 Vue 3 前端项目。

---

## 1 Key 命名：4 段式 + 命名空间

**PROF-FE-601** i18n Key MUST 遵循 4 段式命名空间：`{moduleName}.{pageName}.{elementName}.{actionName}`。 [MUST]

```
格式：{moduleName}.{pageName}.{elementName}.{actionName}

示例：
✅ moduleA.list.btn.create        （模块A.列表页.按钮.新增）
✅ moduleA.editor.title            （模块A.编辑页.标题）
✅ moduleA.list.col.name           （模块A.列表页.列.名称）
✅ moduleA.editor.label.code       （模块A.编辑页.标签.编码）
✅ moduleA.message.deleteConfirm   （模块A.消息.删除确认）

❌ common.save                     （无命名空间，多模块必冲突）
❌ moduleA.btn.create              （缺 pageName 段）
❌ saveBtn                          （无命名空间）
```

---

## 2 语言包结构

**PROF-FE-602** 模块语言包 MUST 放在 `modules/{m}/locales/`，按 `zh-CN.ts` / `en-US.ts` 拆分。 [MUST]

```typescript

  list: {
    title: '{Entity}列表',
    btn: {
      create: '新增',
      edit: '编辑',

    col: {
      name: '名称',
      code: '编码',
      status: '状态',
      createdAt: '创建时间',
    },
  },
  editor: {

      name: '名称',
      code: '编码',
      description: '描述',
    },

      name: '请输入名称',

  message: {
    createSuccess: '创建成功',
    updateSuccess: '更新成功',
    deleteSuccess: '删除成功',
    deleteConfirm: '确定要删除"{name}"吗？',

```

## 3 铁律清单

| 规则 | 说明 |
|------|------|
| **PROF-FE-604** | 禁止使用通用 key（`common.save`、`app.confirm`）。[MUST] |
| **PROF-FE-605** | Key MUST 以模块名开头（camelCase）。[MUST] |
| **PROF-FE-606** | 嵌套层级 ≤ 4 层。[MUST] |
| **PROF-FE-607** | `zh-CN.ts` 与 `en-US.ts` MUST 同步维护。[MUST] |
| **PROF-FE-608** | 禁止中英文混在一个 key 中。[MUST] |
| **PROF-FE-609** | 翻译缺失时 fallback 到 i18n 兜底文案（在 `core/i18n/` 中定义）。[MUST] |
| **PROF-FE-610** | 文案中的动态值 MUST 用 `{name}` 占位符，禁止字符串拼接。[MUST] |

---

## 4 动态值占位符

**PROF-FE-611** 文案中的动态值（用户输入、字段值等） MUST 用 `{name}` 占位符。 [MUST]

```typescript
// ✅ 正确：使用占位符
export default {
  message: {
    deleteConfirm: '确定要删除"{name}"吗？',
    createdAt: '创建于 {time}',
  },
};

// 使用时
t('message.deleteConfirm', { name: user.username });
t('message.createdAt', { time: formatDate(model.createdAt) });
```

```typescript
// ❌ 错误：字符串拼接
const text = '确定要删除"' + user.username + '"吗？';
```

## 5 何时复用 common vs 模块内

| 场景 | 位置 |
|------|------|
| 全站通用（"确定/取消/保存"） | `common/locales/zh-CN.ts` |
| 单模块通用 | `modules/{m}/locales/zh-CN.ts` |
| 跨多个模块的术语 | `common/locales/zh-CN.ts`（在 `common` namespace 下） |

## 6 集成方式参考

### Vue 3 + vue-i18n 9.x

```typescript
// core/i18n/index.ts
import { createI18n } from 'vue-i18n';
import zhCN from '@/common/locales/zh-CN';
import enUS from '@/common/locales/en-US';
import userModuleZhCN from '@/modules/user/locales/zh-CN';
import userModuleEnUS from '@/modules/user/locales/en-US';

export const i18n = createI18n({
  locale: 'zh-CN',
  fallbackLocale: 'en-US',
  messages: {
    'zh-CN': { common: zhCN, user: userModuleZhCN },
    'en-US': { common: enUS, user: userModuleEnUS },
  },
});
```

```typescript
// 在组件中使用
import { useI18n } from 'vue-i18n';

const { t } = useI18n();

<el-button>{{ t('user.list.btn.create') }}</el-button>
```

### Vue 2 + vue-i18n 8.x（历史遗留参考）

```typescript
// core/i18n/index.ts
import Vue from 'vue';
import VueI18n from 'vue-i18n';
import zhCN from '@/common/locales/zh-CN';
import userModuleZhCN from '@/modules/user/locales/zh-CN';

Vue.use(VueI18n);

export const i18n = new VueI18n({
  locale: 'zh-CN',
  fallbackLocale: 'en-US',
  messages: {
    'zh-CN': { common: zhCN, user: userModuleZhCN },
  },
});
```

## 7 禁止行为清单

- ❌ 禁止使用通用 key（`common.save`、`app.confirm`）
- ❌ 禁止中英文混在一个 key
- ❌ 禁止嵌套超过 4 层
- ❌ 禁止字符串拼接动态值（必须用 `{name}` 占位符）
- ❌ 禁止语言包结构与翻译不一致（必须 zh-CN/en-US 同步）
- ❌ 禁止将业务文案散落在组件内（必须走 i18n）

---

*本文件规则适用于 Vue 3 前端项目。*
